## Library Database System 📚

This repository includes a comprehensive library management database system built with SQLite and Python.

### Features
- Complete book catalog with ISBN, authors, publishers, and categories
- Member management with different membership types
- Loan tracking with due dates and returns
- Book reservation system
- Fine management for overdue items
- Book review and rating system
- Staff management

### Quick Start

```bash
# Initialize the database
python library_db.py

# Load sample data
python load_sample_data.py
```

### Documentation
- [Full Documentation](LIBRARY_README.md) - Complete guide with API reference
- [Quick Start Guide](QUICKSTART.md) - Get started in 3 easy steps

### Database Schema
The database includes 11 tables and 4 views:
- Books, Authors, Publishers, Categories
- Members, Staff
- Loans, Reservations, Fines, Reviews
- Optimized views for common queries
